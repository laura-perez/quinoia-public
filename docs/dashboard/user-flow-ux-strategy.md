⚡ Micro-copie émotionnelle - Trigger intelligent

Ne pas afficher systématiquement - TRIGGER :

// Pseudo-code
const showMicroCopy = () => {
// Condition A : User a scrollé 30% de la page
if (scrollPercentage >= 30) return true;

    // Condition B : User est sur la page depuis 5s
    if (timeOnPage >= 5000) return true;

    // Condition C : User revient du bas de page (scroll up)
    if (scrollDirection === 'up' && scrollPercentage < 80) return true;

    return false;

}

Affichage :

- Slide-up smooth (0.3s ease-out)
- Opacity 0 → 1
- Position : Juste avant le sticky banner
- Style : Texte italic, 14px, couleur gris doux

🎯 Règle d'or : Less is More

Budget attentionnel par page :

- ✅ 1 animation majeure (confetti OU fade-in OU slide)
- ✅ 1 message émotionnel (micro-copie OU toast OU badge)
- ✅ 1 CTA principal (gros bouton impossible à rater)
- ❌ Pas de cumul (pas 3 animations + 2 messages + 4 CTAs)

Test qualité :
"Si j'enlève cette animation/message, est-ce que l'utilisateur rate quelque
chose d'important ?"

- OUI → Garder
- NON → Supprimer
